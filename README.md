 🚚 Sistema Inteligente de Gestão de Transporte de Cargas

## 📋 Descrição do Projeto

Este projeto foi desenvolvido em Python com o objetivo de auxiliar no controle de transporte de cargas. O sistema coleta informações do veículo e da carga transportada, realiza validações e informa se o transporte pode ser realizado de forma segura.

## 🎯 Objetivos

- Coletar dados fornecidos pelo usuário.
- Utilizar estruturas condicionais para tomada de decisão.
- Validar informações inseridas.
- Gerar relatórios claros e objetivos.
- Aplicar conceitos fundamentais da programação em Python.

## ⚙️ Funcionalidades

✅ Cadastro do motorista

✅ Cadastro do veículo

✅ Verificação da capacidade máxima

✅ Análise do peso da carga

✅ Relatório detalhado

✅ Tratamento de erros

✅ Alertas de segurança

## 💻 Tecnologias Utilizadas

- Python 3
- Estruturas condicionais (`if`, `elif`, `else`)
- Entrada e saída de dados
- Tratamento de exceções
